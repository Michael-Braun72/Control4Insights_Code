# 6 - n8n Workflow-Automatisierung im Controlling

KI-gestützte Automatisierung von Controlling-Prozessen mit n8n.

## Themen

- n8n Grundlagen: Nodes, Workflows, Trigger
- Daten-Pipelines: Excel/CSV-Import, Transformation, Export
- KI-Integration: LLM-Nodes für automatische Kommentierung
- Reporting-Automatisierung: Daten sammeln, aufbereiten, versenden
- Praxisbeispiel: Automatischer Monatsbericht per E-Mail
