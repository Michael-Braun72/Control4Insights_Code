# 1 - Prompt Engineering für Controller

Grundlagen und fortgeschrittene Techniken für effektives Prompting im Controlling-Kontext.

## Themen

- Prompt-Grundlagen: Rolle, Kontext, Aufgabe, Format
- Controlling-spezifische Prompt-Patterns (Varianzanalyse, Forecasting, Reporting)
- Chain-of-Thought für komplexe Finanzanalysen
- Few-Shot-Prompting mit Controlling-Beispielen
- Prompt-Templates für wiederkehrende Aufgaben
