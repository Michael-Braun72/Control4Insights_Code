# KI im Controlling - Schulungsunterlagen

Strukturierte Schulungsmaterialien zum Einsatz von KI-Tools im modernen Controlling.

## Modulübersicht

| Modul | Thema | Beschreibung |
|-------|-------|--------------|
| **0_Presentation** | Gesamtpräsentation | Übergreifende Schulungspräsentation "KI im Controlling" |
| **1_Prompting** | Prompt Engineering | Grundlagen effektiver Prompts für Controlling-Aufgaben |
| **2_Copilot** | Microsoft Copilot | Copilot in Excel, Power BI und M365 für Controller |
| **3_Claude** | Anthropic Claude | Claude für Analyse, Coding und Reporting im Controlling |
| **4_ChatGPT** | OpenAI ChatGPT | ChatGPT für Ad-hoc-Analysen und Textgenerierung |
| **5_Perplexity** | Perplexity AI | Perplexity für Research und quellenbasierte Recherche |
| **6_n8n** | n8n Workflows | KI-gestützte Automatisierung mit n8n im Controlling |

## Zielgruppe

- Controller und Business Partner Controller
- Finance-Teams mit Interesse an KI-gestützten Workflows
- Führungskräfte (CFO/COO), die KI-Einsatz im Controlling bewerten

## Aufbau

Jedes Modul enthält:
- Praxisbeispiele mit Controlling-Bezug
- Hands-on-Übungen
- Tipps und Best Practices für den produktiven Einsatz
